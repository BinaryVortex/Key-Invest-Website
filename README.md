# Key Invest Website

![Key Invest Website Screenshot](./Screenshot%202025-12-16%20at%2014.18.13.png)

A professional, modern investment company website built with React, Vite, and Tailwind CSS. This project features a responsive design with high-performance components and smooth animations.

## 🚀 Features

- **Responsive Design**: Optimized for all screen sizes from mobile to desktop.
- **Modern UI Components**: Built using Radix UI primitives and custom-styled components.
- **Dynamic Sections**:
  - **Hero**: Eye-catching introduction to the company's value proposition.
  - **About**: Insights into the company's mission and history.
  - **Services**: Detailed breakdown of investment offerings.
  - **Team**: Highlights of the professional expertise behind the firm.
  - **Contact**: Integrated contact for client outreach.
- **Animations**: Fluid transitions and interactive elements using `framer-motion` (motion).
- **Data Visualization**: Charts and metrics powered by `recharts`.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **UI Library**: [Radix UI](https://www.radix-ui.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Form Handling**: [React Hook Form](https://react-hook-form.com/)

## 📦 Getting Started

### Prerequisites

- Node.js (version 18 or higher recommended)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd Key-Invest-Website-master
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   pnpm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `src/app/components`: Core website sections (Hero, About, Services, etc.)
- `src/app/ui`: Reusable UI components built with Radix UI.
- `src/styles`: Theme and global styling configuration.
- `guidelines/`: Project documentation and design guidelines.
